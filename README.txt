Pliki:

- style.css
- script.js

## GitHub Pages
1. Utwórz nowe repozytorium na GitHubie.
2. Wgraj wszystkie 3 pliki do repozytorium.
3. Wejdź w Settings → Pages.
4. W sekcji "Build and deployment" wybierz "Deploy from a branch".
5. Wybierz branch `main` i folder `/ (root)`.
6. Zapisz i poczekaj, aż GitHub utworzy stronę.

Pamiętaj, żeby w `index.html` zmienić tekst wiadomości na własny.
